# ECL Patent License

The **ECL Patent License (ECL-PL)** project is developing an optional, standalone patent-licensing instrument for the Exergism Commons ecosystem.

## Status

**Architecture/bootstrap stage. No patent license has been released yet.**

This repository deliberately does not imply, create, or publish a patent grant merely by existing, accepting contributions, referencing the Exergic Commons License, or describing a proposed licensing model. A patent grant must ultimately be express, attributable to a Patent Licensor with authority to grant it, bounded to defined patent rights, and attached to an immutable patent-grant artifact.

## Architectural direction

The current design direction is:

- ECL remains a copyright/software-rights license and does not itself grant patent rights.
- ECL-PL is a separate, optional companion instrument.
- Applying ECL does not automatically apply ECL-PL.
- Applying ECL-PL does not imply ownership or control of any patent.
- Patent grants are independently versioned and attributable.
- A patent grant may explicitly reference an immutable ECL Bundle, but no relationship is inferred from mutable repository or governance state.
- Patent-specific termination, exhaustion, competition-law, chain-of-title, sublicensing, downstream, and jurisdictional questions require independent treatment.

The project will define the architecture and provenance model before drafting the operative `PATENT-LICENSE` text.

## Legal status

This is an experimental licensing project. Nothing in this repository is legal advice, and no draft should be relied upon for high-consequence patent licensing without qualified patent/licensing counsel in the relevant jurisdictions.
